SentinelAudit

An automated security and compliance framework for remote Windows workstations.

The problem

When employees work remotely, their laptops sit outside the corporate firewall, and the IT team has no simple way to confirm each machine is still secure. Checking by hand is slow and easy to skip, while the commercial tools that automate it are expensive and complex to run.

SentinelAudit scans a Windows workstation, scores it against a security baseline, and shows the result on a dashboard. It is built entirely from free, open-source tools.

How it works

1. Scanner

Reads encryption, firewall, and patch status from Windows. Read-only by design, so it can inspect a machine but never change one.

2. Scoring engine

Weighs each finding against a security baseline and produces a score out of 100. Every point traces back to a rule you can read.

3. Dashboard

Presents the score visually, with failing controls in red and passing ones in green, and all timestamps standardised to UTC.
